Zebin Zhang

I am currently a second-year Ph.D. student at the School of Integrated Circuits, Peking University, working in the Ultra Low-Power Logic and Memory Group advised by Prof. Qianqian Huang. My research focuses on hafnia-based ferroelectric memory devices, with particular interests in non-destructive readout mechanisms and energy-efficient computing-in-memory.

I received my B.Eng. degree from Peking University in 2025. My undergraduate thesis studied a hafnium-oxide-based ferroelectric domain-wall memory and its applications.

Publications

Selected conference work in reverse chronological order.

Novel Hafnia-based Ferroelectric Domain Wall Memory with Improved Memory Window and Non-destructive Read for High-Accuracy In-Memory Computing

Zebin Zhang, Shengjie Cao, Zhiyuan Fu, Qianqian Huang, and Ru Huang

IEEE Electron Devices Technology and Manufacturing Conference (EDTM), 2026.

This work demonstrates an HZO ferroelectric domain-wall memory that stores data using polarization-modulated conductive domain walls. The device supports 100 mV non-destructive read, a memory-window ratio above 3, read endurance above 109 cycles, and over 92% inference accuracy in an MLP simulation.

First Experimental Demonstration of Dual-layer Cross-Point Ferroelectric Capacitor Array based TCAM for Hyperdimensional Computing

Zebin Zhang†, Hao Zheng†, Shengjie Cao, Jiayan Zhu, Weikai Xu, Zhiyuan Fu, Qianqian Huang, and Ru Huang († equal contribution)

IEEE Silicon Nanoelectronics Workshop (SNW), 2026.

This work demonstrates a vertically stacked dual-layer HZO FeCAP TCAM for charge-domain associative search. Two complementary FeCAPs share a match line to store ternary 0/1/X states in a compact 4F² cell; the fabricated 1 kbit array provides a 3.85 pC sensing margin and endurance above 109 cycles.
